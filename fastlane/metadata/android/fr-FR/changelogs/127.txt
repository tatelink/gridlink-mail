Sterna envoie et lit désormais les e-mails chiffrés avec OpenPGP. Installez l'application compagnon OpenKeychain, choisissez votre clé dans les réglages du compte, et un bouton cadenas dans la fenêtre de rédaction vous permet de signer vos messages (pour prouver qu'ils viennent de vous) et de les chiffrer (pour que seul votre destinataire puisse les lire), sur les comptes JMAP comme IMAP. Les e-mails chiffrés reçus sont déchiffrés à l'ouverture, avec une pastille colorée indiquant si la signature est valide. Le contenu déchiffré n'est jamais écrit sur le disque ; une pièce jointe ouverte est écrite dans l'espace de stockage de l'application jusqu'au vidage du cache. L'objet du message n'est pas chiffré. Un petit guide se trouve dans ENCRYPTION.md.
