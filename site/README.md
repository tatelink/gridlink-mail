# `site/` — the sternamail.org brochure

One page, nine languages, no CMS, no framework, no build chain. `build.py` reads the texts that
already exist in the repository, fills `template.html`, and writes a finished site into `_out/`.

Decisions behind all this live in the maintainer's notes, outside this repository.

```
site/
├── build.py            # the generator — standard library only
├── template.html       # the page, and the repeated blocks it is made of
├── style.css           # hand-written, copied verbatim
├── i18n/<lang>.txt     # the page's own strings, `key = value`
├── assets/screens/     # screenshots, resized once (see below)
├── nginx-snippet.conf  # GENERATED — the outgoing redirects
└── _out/               # GENERATED — what gets deployed (not in git)
```

## Build

Nothing is installed on the host, ever. Any bare Python image will do:

```bash
docker run --rm --user "$(id -u):$(id -g)" \
  -v "$PWD":/work -w /work \
  python:3.13-slim python3 site/build.py
```

Add `--check` to parse and validate without writing anything. The build fails loudly, and refuses
to produce a half-filled page, when:

* a language file is missing a key, or carries one English does not have;
* a `full_description.txt` no longer has its four `Heading:` blocks (a translation drifted);
* a marker in the template has no value.

## Where each piece of text comes from

| On the page | Source | Why |
|---|---|---|
| The one-line pitch | `fastlane/metadata/android/<locale>/short_description.txt` | already translated, already the F-Droid pitch |
| The feature lists and their headings | `…/full_description.txt` | same, and it can never contradict the store listing |
| Everything else (buttons, guarantees, captions) | `site/i18n/<lang>.txt` | it does not exist anywhere else |
| Screenshots | `site/assets/screens/`, else `docs/screenshots/` | the same images the README and F-Droid show |
| Logo, and the browser-tab icon | `docs/logo.png` | one mark, one file, nothing to redraw |

**Never copy an app feature into `i18n/`.** The rule that keeps this page cheap is that the app's
own description is the only description. Adding a bullet here means writing it twice, in nine
languages, forever.

**Nothing on the page ages by itself**: no version number, no release date, no counters, no news.
The F-Droid button always tells the truth without anyone touching it. Keep it that way.

## Screenshots

The generator never touches an image, it only copies. Resizing is a one-off gesture whose result is
committed, done in the ImageMagick image that is already on the machine:

```bash
docker run --rm --user "$(id -u):$(id -g)" \
  -v "$PWD":/work --entrypoint sh dpokidov/imagemagick -c '
    mkdir -p /work/site/assets/screens
    for f in /work/docs/screenshots/*.png; do
      magick "$f" -resize 720x1280 -strip -colors 192 \
        -define png:compression-level=9 "/work/site/assets/screens/$(basename "$f")"
    done'
```

Half the size, then a 192-colour palette: a flat Material interface quantises without a visible
loss, and the five screenshots drop from about 900 kB to under 200 kB. Check one by eye afterwards.

Until `site/assets/screens/` exists, `build.py` falls back to the full-size originals and says so.
The five it looks for are `inbox-light`, `inbox-dark`, `message`, `compose` and `settings`; the
list lives at the top of `build.py`, next to the caption keys they use.

## Adding or changing a language

1. Copy `i18n/en.txt`, translate the values (keys stay untouched).
2. Add the locale to `LOCALES` in `build.py`: the folder name under `fastlane/metadata/android/`,
   the HTML language code, and the URL folder.
3. Rebuild. `hreflang`, the language menu and the sitemap follow on their own.

A language only becomes available once fastlane carries its two description files, since that is
where the body of the page comes from.

## Deploy

`_out/` is a directory of static files: any web server that can serve a directory will do. How the
live site is actually served is the maintainer's own hosting, documented outside this repository.

The page names no forge: `/download`, `/source`, `/issues`, `/apk`, `/obtainium`, `/licence` and
`/privacy` are all redirects the server holds. Moving the code somewhere else is one line of server
config, not a rebuild of every listing that points here. `nginx-snippet.conf` is regenerated by
`build.py` from the same table the hrefs come from, so the two cannot drift.

`.well-known/security.txt` carries an expiry one year after the build. Rebuilding refreshes it.

## Translations to review

`i18n/en.txt` and `i18n/fr.txt` are written by the maintainer. The other seven were drafted with
the English as reference and have not been reviewed by a native speaker. They are short and factual,
but if a reporter offers a correction, it is worth taking.
